# OpenSpec

OpenSpec is the canonical home for accepted behavior and non-trivial behavioral changes in this repository.

- `specs/` contains current accepted requirements.
- `changes/` contains active non-trivial behavior-change artifacts when needed.

GitHub Issues/Projects remain the canonical backlog and work-status system; OpenSpec is not a task tracker.

If OpenSpec tooling is unavailable, maintain the Markdown structure and semantics manually rather than moving requirements into chat history or architecture prose.
